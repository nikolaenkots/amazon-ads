# Расписание второй установки. Пути под VM margoads
# (/home/nikolaenko_ts/margoads); для другой машины поправьте путь.
# Ставится так:  crontab ~/margoads/deploy/crontab.txt
#
# Время указано по Варшаве: CRON_TZ снимает вопрос перехода на зимнее время,
# иначе запуск пришлось бы дважды в год сдвигать вручную.
CRON_TZ=Europe/Warsaw

# 10:00 — синхронизация структуры кампаний, сразу за ней сбор статистики.
# Обе команды в одной строке, как на основном аккаунте: отчёты стартуют сразу
# после синхронизации, а не по отдельному расписанию — так статистика гарантированно
# ложится на актуальный список кампаний и не надо угадывать, сколько займёт синк.
# Разделитель «;», а не «&&»: если синхронизация упадёт на одном гео, статистику
# всё равно собираем.
# Сбор идёт так же, как на основном аккаунте: все отчёты заказываются сразу,
# дальше общий поллинг и загрузка по мере готовности. Если Amazon начнёт
# ограничивать частоту (видно в collect.log), добавьте --batch 8 — отчёты
# пойдут пачками по восемь.
0 10 * * * cd $HOME/margoads && venv/bin/python scripts/auto_sync_campaigns.py >> $HOME/margoads/logs/sync.log 2>&1; cd $HOME/margoads && venv/bin/python scripts/auto_collect.py >> $HOME/margoads/logs/collect.log 2>&1
